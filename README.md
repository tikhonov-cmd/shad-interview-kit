# Исследование ШАД

Гайды для интервьюера, гипотезы четырёх пар и материалы участника.

- Интервьюер: https://tikhonov-cmd.github.io/shad-interview-kit/
- Гипотезы и вопросы: https://tikhonov-cmd.github.io/shad-interview-kit/research.html
- Участник: https://tikhonov-cmd.github.io/shad-interview-kit/student/

## Как провести интервью

Открой сайт и выбери назначенный код интервью. Группа, вопросы и порядок материалов подставятся автоматически. Кнопка «Ссылка студенту» копирует отдельную ссылку участнику на выбранные материалы. Гайды и подсказки не отображаются на странице участника.

Кнопка «Тёмная тема» вверху переключает оформление страниц интервьюера и участника, в том числе отдельно открытых материалов. Выбор сохраняется в браузере и синхронизируется с открытым просмотром. Материалы исследования показываются в исходных цветах, а печатная версия остаётся светлой.

Перед первым интервью прочитай раздел с гипотезами и свою пару. Для заметок скачай бланк с сайта и сохрани отдельную копию. Ответы участников сайт не собирает и не хранит.

Внизу сайта есть ссылка на ZIP для работы без интернета. Распакуй его целиком и открой `Локальный комплект/index.html` в браузере. Публичные ссылки участнику требуют интернета.

## Как обновить сайт

1. Внеси изменения в `content/kit.json` (вопросы, группы, пары, маршруты) или в `site/` (страницы, оформление и материалы).
2. Сохрани изменения в ветке `main`.
3. Дождись зелёного статуса **Publish interview kit** в разделе **Actions**. Сайт по прежней ссылке и скачиваемый ZIP обновятся вместе.

На открытой странице раз в минуту и при возвращении к вкладке проверяется версия. Если опубликовано обновление, появляется уведомление. Оно не переключает вопросы и не перезагружает текущую беседу. Нажми «Обновить после интервью», когда будешь готов.

Не добавляй в этот репозиторий заполненные бланки, записи интервью, персональные данные или доступы к внешним сервисам. Страницы интервьюера и участника разделены по назначению, а не системой авторизации.

## Структура

- `content/kit.json` — единый источник вопросов и маршрутов.
- `site/` — исходники сайта, локальные видео, изображения и шрифты.
- `site-config.json` — постоянный адрес сайта.
- `scripts/build.py` — сборка сайта, проверка локальных ссылок и создание ZIP.
- `.github/workflows/pages.yml` — публикация через GitHub Pages.
- `dist/` — результат сборки; не хранится в Git.

Локальная сборка не требует сторонних библиотек:

```sh
python3 scripts/build.py
python3 -m http.server 8767 --bind 127.0.0.1 --directory dist
```

Открой http://127.0.0.1:8767/ для проверки. Не редактируй файлы в `dist/`: при следующей сборке они создаются заново.
